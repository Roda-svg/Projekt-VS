## <span style="color:#483D8B;">Vad är VS Code?</span>
Visual Studio Code är ett program som man använder för att skriva kod. Det används bland annat när man jobbar med webbsidor och programmering.

I VS Code kan man samla sina filer och mappar på ett ställe. Det gör det enklare att hitta och hålla koll på sitt arbete.

---

## <span style="color: #7054A5;">1. Explorer - Filer och mappar</span>
- Explorer är den del där man får en överblick över hela sitt projekt.
- Här kan man se alla filer och mappar som tillhör projektet och enkelt hålla ordning på dem.
- Man kan skapa nya filer och mappar, byta namn på dem eller ta bort sådant man inte längre behöver.
- Det gör det enklare att organisera sitt arbete och snabbt hitta filen man vill fortsätta arbeta med dem.

Enkelt sagt: Explorer fungerar ungefär som mapparna på datorn, där man samlar och organiserar sina projektfiler.

---

## <span style="color: #7054A5;">2. Editor - Där man skriver kod</span>
- Editorn är den stora arbetsytan i mitten av VS Code.
- Det är här man skriver, läser och ändrar sin kod.
- Man kan öppna flera filer samtidigt och växla mellan dem utan att behöva stänga den ena.
- Programmet hjälper också till genom att exmplvis markera olika delar av koden med färger, så att den blir lättare att läsa och förstå.

Enkelt Sagt: Editorn är själva arbetsytan där man bygger och utvecklar sitt projekt genom att skriva kod.

---
## <span style="color: #7054A5;">3. Terminal - Skriva kommandon</span>
- Terminalen är ett verktyg där man kan skriva in kommandon för att utföra olika uppgifter.
- Den kan exempelvis användas för att starta ett projekt, installera program och köra kod.
- Man kan också använda terminalen tillsammmans med Git för att spara ändringar och hålla koll på olika versioner av sitt projekt.
- Fördelen är att man kan utföra dessa uppgifter direkt i VS Code utan att behöva öppna ett seperat program.

Enkelt sagt: Terminalen är ett ställe där man skriver instruktioner till datorn för att utföra olika uppgifter.

---

## <span style="color: #7054A5;">4. Extensions - Tillägg</span>
- Extensions är extra funktioner som man kan installera i VS Code för att anpassa programmet efter sina behov.
- De kan göra programmeringen enklare och hjälper till att förbättra arbetsflödet.
- Det finns tillägg som exmpelvis hjälper till med stavning i kod, färgmarkeringar, formatering och att hitta fel i koden.
- Man kan själv välja vilka tillägg man vill installera beroende på vd man arbetar med.

Enkelt sagt: Extensions fungerar som extra verktyg eller appar som ger VS Code fler Funktioner.

---

## <span style="color: #483D8B;">5. Kortkommandon på Mac</span>
| **Kommando** | **Funktion** |
| --- | --- |
| `Cmd + S` | Spara|
| `Cmd + Z` | Ångra |
| `Cmd + C` | Kopiera |
| `Cmd + V` | Klistra in |
| `Cmd + P` | Hitta en fil |

---

## <span style="color: #483D8B;">6. Att tänka på!</span>
När man börjar använda VS Code kan det kännas som att det finns väldigt mycket att lära sig. Men man behöver inte förstå allt direkt.

Börja man att lära dig var filerna finns, var man skriver koden och hur de olika funktionerna fungerar. Resten kommer efter hand!
